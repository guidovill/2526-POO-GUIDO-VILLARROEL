# Gestión de Tareas con Tkinter

Aplicación GUI desarrollada en Python con Tkinter para gestionar una lista de tareas pendientes.

## Funcionalidades
- Añadir nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Uso de botones y atajos de teclado.

## Atajos de teclado
- Enter: añadir nueva tarea.
- C: marcar tarea seleccionada como completada.
- D o Delete: eliminar tarea seleccionada.
- Escape: cerrar la aplicación.

## Requisitos
- Python 3 instalado.
- Tkinter disponible en la instalación de Python.
