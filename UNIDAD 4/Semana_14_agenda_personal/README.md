# Agenda Personal - Semana 14

Aplicación GUI desarrollada en Python con Tkinter para la materia de Programación Orientada a Objetos.

## Descripción
Esta aplicación funciona como una agenda personal básica. Permite registrar eventos o tareas programadas mediante una interfaz gráfica amigable.

## Funcionalidades
- Visualización de eventos en una tabla (TreeView)
- Selección de fecha mediante DatePicker
- Ingreso de hora y descripción
- Agregar nuevos eventos
- Eliminar eventos seleccionados
- Salir de la aplicación

## Estructura
- `main.py`: archivo principal de la aplicación
- `README.md`: descripción general del proyecto

## Requisitos
- Python 3
- Tkinter
- tkcalendar
