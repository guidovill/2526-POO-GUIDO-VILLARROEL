# Semana 13 - Conceptos fundamentales de interfaces gráficas de usuario

## Descripción
Este proyecto consiste en una aplicación GUI básica desarrollada en Python con Tkinter.  
La aplicación permite ingresar el título de un libro y su autor, agregarlos a una tabla visual y limpiar la información ingresada o seleccionada.

## Funcionalidades implementadas
- Ventana principal con título descriptivo.
- Uso de etiquetas (labels).
- Uso de botones.
- Uso de campos de texto.
- Uso de una tabla para mostrar datos.
- Botón **Agregar** para registrar información.
- Botón **Limpiar** para borrar campos o eliminar el registro seleccionado.
- Manejo de eventos con clics de botones y teclas del teclado.

## Tecnologías utilizadas
- Python 3
- Tkinter
- ttk (interfaz mejorada de Tkinter)
