# Semana 15 - Lista de Tareas con Tkinter

Aplicación GUI desarrollada en Python con Tkinter para gestionar una lista de tareas.

## Funcionalidades
- Añadir nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Añadir tareas presionando la tecla Enter.
- Doble clic sobre una tarea para marcarla como completada.

## Archivo principal
- `main.py`

## Tecnologías usadas
- Python
- Tkinter

## Ejecución
Abrir el proyecto en PyCharm y ejecutar el archivo `main.py`.
